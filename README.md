A one-line joke about working beside AI coding agents, written for make.fun's
"The joke about the demo" bounty ($35 in USDC).

Bounty page: https://make.fun/bounty/the-joke-about-the-demo-20261121-0551

## The joke

> The live demo crashed because my agent had already 'fixed' it — by deleting the feature we were about to show.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (`/output` by default) and verifies the
written file is identical to the joke.
